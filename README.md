MINI PROJECT :- DATA ANALYTICS 
# IBM HR ANALYTICS – COMPLETE MINI PROJECT

## Project Overview

This project focuses on analysing IBM HR Analytics employee data through three major stages: **Data Cleaning using Microsoft Excel, Data Visualisation using Microsoft Power BI, and Report Creation and Analysis.**

The main purpose of this project is to transform raw employee data into meaningful information through data preparation, visualisation and interpretation. The final outcome is an organised Power BI dashboard and a comprehensive report that helps understand workforce characteristics and important HR indicators.

---

## 1. Project Objectives

The major objectives of this project are:

- To clean and organise raw employee data using Microsoft Excel.
- To identify and correct data quality issues.
- To prepare structured data for analysis.
- To create meaningful visualisations using Microsoft Power BI.
- To analyse employee performance, satisfaction, compensation and other HR indicators.
- To develop an interactive and informative HR dashboard.
- To prepare a comprehensive report explaining the process, findings and recommendations.

---

# STAGE 1: DATA CLEANING USING MICROSOFT EXCEL

## 2. Introduction to Data Cleaning

Data cleaning is the first and most important stage of the project. Raw datasets may contain missing values, duplicate records, inconsistent formats and other data quality issues.

In this project, Microsoft Excel was used to inspect, organise and prepare the IBM HR Analytics dataset before importing it into Power BI.

## 3. Activities Performed

The following activities were carried out during the data cleaning process:

1. Imported and inspected the original dataset in Microsoft Excel.
2. Reviewed column names and data structure.
3. Checked for missing or blank values.
4. Identified and checked duplicate records.
5. Reviewed data formats and consistency.
6. Corrected data quality issues wherever required.
7. Ensured that numerical and categorical columns were organised properly.
8. Prepared the cleaned dataset for Power BI.

## 4. Outcome of Stage 1

The raw employee dataset was organised into a cleaner and more consistent format.

**Output:** Cleaned IBM HR Analytics dataset ready for data visualisation and analysis.

---

# STAGE 2: DATA VISUALISATION USING MICROSOFT POWER BI

## 5. Introduction to Data Visualisation

After completing data cleaning, the prepared dataset was imported into Microsoft Power BI.

Power BI was used to convert employee records into visual representations such as KPI cards, charts and analytical dashboards.

The purpose was to make the data easier to understand and to identify important patterns within the workforce.

## 6. Activities Performed

The following activities were completed:

1. Imported the cleaned Excel dataset into Power BI.
2. Inspected the dataset and its fields.
3. Checked the data model and relevant relationships where required.
4. Created DAX measures for important HR indicators.
5. Designed KPI cards to display summary information.
6. Created charts to analyse employee-related information.
7. Organised visuals into separate dashboard pages.
8. Applied appropriate titles, labels and formatting.
9. Reviewed the dashboard to improve readability and presentation.

## 7. Key Areas Analysed

The Power BI dashboard covers the following analytical areas:

### A. Employee Overview
- Total employee count.
- Employee distribution.
- Age and education-related information.
- Job roles and job levels.

### B. Employee Experience
- Total working years.
- Years at the company.
- Previous company experience.
- Employee distribution based on experience.

### C. Performance Analysis
- Performance rating distribution.
- Employee performance indicators.
- Comparison of performance rating with salary hike.

### D. Compensation Analysis
- Monthly income.
- Average percentage salary hike.
- Compensation-related comparisons.

### E. Employee Satisfaction
- Job satisfaction.
- Environment satisfaction.
- Job involvement.
- Work-life balance.

### F. Work Pattern Analysis
- Overtime information.
- Training information.
- Comparison of selected work-related indicators.

### G. Attrition Analysis
- Employee attrition.
- Attrition rate.
- Comparison of attrition across relevant employee categories.

## 8. Dashboard Structure

The Power BI report was organised into two main analytical pages:

**Page 1 – Employee Overview**

Provides a general overview of the workforce using employee-related indicators, demographic information, job roles, experience and relevant HR metrics.

**Page 2 – Performance and Employee Analysis**

Focuses on performance ratings, salary hikes, satisfaction indicators, work-life balance and other employee-related comparisons.

## 9. Outcome of Stage 2

The cleaned dataset was transformed into a visual and interactive Power BI report.

**Output:** A Power BI dashboard presenting workforce information and HR analytics through charts, KPI cards and other visual elements.

---

# STAGE 3: REPORT CREATION AND ANALYSIS

## 10. Introduction to Reporting

The final stage involved preparing a comprehensive report based on the data cleaning process and the Power BI dashboard.

The purpose of reporting is to explain the project methodology, describe the visualisations, interpret the important analytical areas and present recommendations.

## 11. Activities Performed

The reporting stage included:

1. Documenting the project objectives and scope.
2. Explaining the Excel data cleaning process.
3. Describing the Power BI dashboard structure.
4. Explaining the major HR indicators.
5. Interpreting the visual analysis.
6. Identifying important observations and areas for further investigation.
7. Providing recommendations based on the analysis.
8. Preparing the final project documentation.

## 12. Key Analytical Insights

The dashboard provides opportunities to understand:

- The composition and distribution of employees.
- Differences in workforce experience and job roles.
- The distribution of employee performance ratings.
- Salary hike patterns and compensation indicators.
- Employee satisfaction and work-life balance.
- Overtime patterns.
- Employee attrition across relevant categories.

These observations can help HR teams identify areas that may require further investigation.

The dashboard is a descriptive analytical tool. It identifies patterns in the available dataset but does not independently establish the causes of employee behaviour or attrition.

## 13. Recommendations

Based on the analytical areas covered in the project, the following recommendations can be considered:

1. Regularly monitor employee satisfaction and workplace environment indicators.
2. Review employee groups showing comparatively higher attrition.
3. Examine overtime patterns to identify possible workload concerns.
4. Review performance ratings and salary hike patterns transparently.
5. Encourage a healthy work-life balance.
6. Use employee data to support workforce planning and HR decision-making.
7. Regularly update and validate HR reports to maintain data accuracy.
